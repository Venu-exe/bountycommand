# BountyCommand 🎯

All-in-one bug bounty command center — runs entirely in the browser, offline, persisted to localStorage.

## Features
- 📊 Dashboard with live stats
- 🎯 Target manager
- 🐛 Findings tracker (severity, CVSS, status)
- 🧪 Payload Lab (7 vuln types, 6 encodings, WAF bypass)
- 📐 CVSS 3.1 calculator
- 📄 Report generator (H1/Bugcrowd/Intigriti/generic)
- 📝 Notes scratchpad
- 💾 All data stays in your browser (localStorage) — no backend, no tracking

## Usage
Just open `index.html` in a browser. No install, no server, no dependencies.

Live: https://venu-exe.github.io/bountycommand/ (if Pages enabled)
